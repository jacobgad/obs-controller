# OBS Controller Add-ons

Home Assistant add-on repository.

## Add-ons

- **[OBS Controller](./obs-controller/)** — MQTT bridge exposing OBS Studio instances as Home Assistant devices via obs-websocket.

## Installation

1. In Home Assistant go to **Settings → Add-ons → Add-on Store**.
2. Open the overflow menu (⋮) → **Repositories**.
3. Add `https://github.com/jacobgad/obs-controller`.
4. Install **OBS Controller**.
